# سراديب — النسخة البرمجية الخاصة

نسخة مستقلة بالكامل عن WordPress/Elementor، مخصصة لموقع **saradeeeb.com** وتعمل على PHP + MariaDB.

## أهم ما بداخلها
- واجهة عربية داكنة سينمائية ومتجاوبة، مع مظهر فاتح اختياري.
- لوحة إدارة خاصة `/admin`.
- إدارة صفحات ثابتة متعددة اللغات (من نحن، الخصوصية، التواصل وغيرها).
- لوحة كتّاب `/writer` وصلاحيات: مدير، محرر، كاتب موثوق، كاتب.
- التسجيل ككاتب مع موافقة الإدارة قبل التفعيل.
- سير عمل المقال: مسودة → مراجعة → تعديلات → منشور / مؤرشف.
- أربع لغات مستقلة: العربية `ar`، الإنجليزية `en`، الإسبانية `es`، الروسية `ru`.
- كل ترجمة تحفظ كمحتوى كامل مستقل (عنوان، slug، محتوى، وصف، SEO) وترتبط بمجموعة المقال نفسها.
- مبدّل لغة المقال ينقل إلى النسخة المقابلة من المقال نفسه.
- `hreflang` + canonical + Article schema + sitemap.xml + robots.txt.
- نظام إعلانات مخصص للمواضع واللغات.
- استيراد WordPress من ملف WXR XML.
- تحويلات 301 للروابط القديمة المستوردة عندما تكون متاحة.
- رفع صور آمن نسبيًا مع فحص MIME والصورة الفعلية وحد للحجم.
- CSRF، جلسات آمنة، PDO prepared statements، Argon2id لكلمات المرور، وصلاحيات حسب الدور.

## متطلبات الاستضافة
- PHP 8.1 أو أحدث (يفضل 8.2/8.3/8.4).
- MariaDB/MySQL.
- PDO + pdo_mysql.
- mod_rewrite / دعم `.htaccess`.
- امتداد `fileinfo` وSimpleXML.
- HTTPS.

## الرفع إلى Hostinger
1. من hPanel أنشئ قاعدة بيانات MariaDB/MySQL وسجل: اسم القاعدة، اسم المستخدم، كلمة المرور.
2. خذ نسخة احتياطية كاملة من موقع WordPress الحالي وقاعدة بياناته. لا تحذف القديم قبل فحص الجديد.
3. يفضل اختبار النسخة أولًا على Subdomain مثل `new.saradeeeb.com` أو مجلد مؤقت.
4. ارفع محتويات هذه الحزمة إلى `public_html` للموقع التجريبي.
5. تأكد أن PHP مضبوط على 8.1+.
6. افتح `/install.php` وأدخل بيانات قاعدة البيانات ورابط الموقع وحساب المدير.
7. بعد نجاح التثبيت **احذف install.php**.
8. سجل الدخول عبر `/ar/login` ثم انتقل إلى `/admin`.
9. لتصدير WordPress الحالي: WordPress → أدوات → تصدير → كل المحتوى. ارفع الملف من: لوحة سراديب → استيراد WordPress.
10. راجع الروابط والصور والمقالات يدويًا قبل تحويل الدومين النهائي.

## Cron اختياري للنشر المجدول
في hPanel → Cron Jobs، شغّل ملف:
`/home/USER/domains/saradeeeb.com/public_html/cron/publish_scheduled.php`
مرة كل 10 أو 15 دقيقة. مسار Hostinger الفعلي يختلف حسب الحساب؛ انسخه من FTP Accounts/SSH.

## ملاحظات أمنية مهمة
- لا تترك `install.php` بعد التثبيت.
- فعّل HTTPS دائمًا.
- أبقِ ModSecurity مفعّلًا ما لم توجد مشكلة محددة.
- استخدم كلمة مرور طويلة لحساب المدير.
- خذ نسخًا احتياطية دورية من الملفات وقاعدة البيانات.
- لا تمنح صلاحية `admin` لكاتب عادي.

## نقل الموقع الحالي بدون خسارة SEO
الترتيب الصحيح: اختبار النسخة → استيراد المحتوى → مطابقة الروابط → فحص 301 → فحص canonical/hreflang → إنشاء sitemap → تحويل الدومين. لا تغيّر روابط المقالات الحالية بلا خريطة تحويلات.

## ما يحتاج بيانات من موقعك الحالي
الكود جاهز للاستيراد، لكن المحتوى الحقيقي والصور الحالية لا يمكن تضمينهما في الحزمة دون ملف WXR/نسخة قاعدة البيانات أو وصول مباشر إلى موقع WordPress. بعد توفير WXR يتم إدخاله من لوحة الإدارة نفسها.
