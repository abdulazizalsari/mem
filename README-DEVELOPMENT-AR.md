# بيئة تطوير Saradeeeb

هذه هي نسخة التطوير النظيفة للمشروع. لا ترفعها إلى الموقع أثناء التطوير.

## المبدأ
- التطوير والاختبار يتمان هنا أولًا.
- لا يتم تعديل قاعدة بيانات الإنتاج أثناء العمل.
- `config/local.php` غير موجود داخل نسخة التطوير النهائية حتى لا تُحفظ أسرار الاستضافة في الحزمة.
- عند التسليم يتم تجهيز ZIP إنتاج واحد فقط.

## VS Code
افتح الملف `saradeeeb.code-workspace` في Visual Studio Code.

## فحص PHP
من Command Palette شغّل المهمة: `PHP: lint project`.

## الاستضافة النهائية
الهدف: Hostinger shared hosting + PHP 8.x + MariaDB.
